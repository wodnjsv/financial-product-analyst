# 개인용 검색 검증 Harness

2026-10-12에 자연어 → 로컬 PostgreSQL → 텍스트 출력 경로에 요청별 검증 기록을 연결했습니다. 설계는 [ADR-0057](../planning/decisions/ADR-0057-personal-verification-harness.md), 작업과 시험 이력은 [작업 계획](../planning/tasks/2026-10-12-verification-harness.md)에 있습니다.

## 실행과 차단 순서

```text
NVIDIA 의도 제안 → 기존 의미 계약·계획 컴파일
  → plan: 질문/실행/데이터셋 pin 일치
  → query: 컴파일러가 소유한 SQL·바인딩 재검증
  → execution: 읽기 전용 조회·결과 매핑
  → evidence_loading: 같은 데이터셋의 원천 근거 조회
  → evidence: 값·출처·시점·원장 연결 검증
  → result_contract: 질문의 상품 범위·조건·단위·기간·정렬·건수 확인
  → 검증된 상품 ID만 다음 작업에 전달
  → final: 검증된 구조의 서버 출력과 최종 텍스트 일치
```

각 SQL 작업은 조회 직전에 실제 DB의 데이터셋 버전·manifest 해시·cutoff를 재확인합니다. 상품 조회와 그 pin 확인은 같은 읽기 전용 repeatable-read 트랜잭션을 사용합니다. 근거 조회도 자신의 트랜잭션에서 같은 pin을 확인하며, 결과가 비어 있어도 생략하지 않습니다. 두 조회가 하나의 공통 트랜잭션인 것은 아니므로 기존 버전별 원장 불변성 정책도 필요합니다. 개인용 데이터셋의 `building` 상태는 유지합니다.

조건·상품 범위나 출처 검증이 실패하면 해당 결과를 후속 작업에 넘기지 않고 최종 답변도 내보내지 않습니다. SQL 성공 뒤 근거 적재가 실패한 경우에는 SQL을 성공으로, 근거 적재를 실패로 기록합니다. 기존 Orchestrator의 허용된 재시도가 실행되면 시도별 실패와 성공을 모두 보존합니다. 조건·출처 오류 같은 검증 실패를 재시도 성공으로 덮어쓸 수 없습니다.

## 검사하는 내용

| 경계 | 검사 |
| --- | --- |
| 계획·SQL | 등록된 의미 계약과 컴파일러 바인딩, request/run/dataset/manifest/cutoff 일치 |
| 원천 | 관측·관계·근거의 연결, 지표 정의·단위·값·날짜, 발행 주체·소스 종류·권한 등급·체크섬 메타데이터 |
| 주최 측 지표 | 기존 mapper의 원본 워크북·열·상품군 소유권. 다른 원본 필드로 대체하지 않음 |
| 관계 | 운용사 원본 역할, 국내 ETF의 KRX·해외 ETF의 SEC 소스 정책 |
| 시점·누락 | 시간대 있는 datetime을 Asia/Seoul 날짜로 변환해 cutoff 확인, 시간대 없는 datetime 거부, 실제 0과 누락 구분 |
| 질문과 결과 | 지정 상품·상품군·검증된 선행 결과 ID, 등록된 조건/연산자, 필드별 날짜·통화·단위·기간, 중복·전체/표시 건수, 반환된 순위 순서·동률·limit |
| 최종 출력 | 검증된 구조를 서버가 렌더링한 텍스트와 정확히 일치. 값·날짜·건수·상품명·출처 변조나 추가 문장 거부 |

미래 만기일은 금융상품의 값이므로 허용합니다. 원천의 공시·관측 시점 검사는 별도로 유지합니다. 문서 원문 속 숫자, 날짜, `[D9]` 같은 문자열을 금융 계산값이나 애플리케이션 인용 ID로 오인하는 숫자 정규식 검사는 사용하지 않습니다. 기존 원문 발췌 계약과 생산용 AtomicClaim/ClaimSupport/CalculationRecord/ClaimGate를 보존합니다.

반환된 행과 조회 계약을 독립적으로 대조하는 검증이며, 미표시 모집단 전체를 다시 조회하여 모든 순위·건수를 재계산하는 별도 엔진은 아닙니다. 등록되지 않은 계산식·자유 요약·자연어 의도 자체의 완전한 정답 판정도 보장하지 않습니다. 회귀 시험에서는 별도 원천 검산 결과와 전체 ID/건수를 비교합니다.

## 보고서 사용

```sh
.venv/bin/python scripts/search_personal_question.py \
  --question '일본 주식형 해외 ETF 중 총보수 0.5% 이하이고 AUM이 있는 상품만 찾아줘.' \
  --api-key-file /path/to/original-workspace/api.txt \
  --display-limit 5 \
  --verification-report data/verification-example.json
```

`--verification-report`는 선택 사항입니다. 새 파일에만 JSON을 저장하며, 기존 경로를 지정하면 API 호출·조회 전에 거부합니다. 텍스트 결과는 기존처럼 표준 출력에 나타납니다. 실패한 실행도 계획 이후의 검증 기록이 있다면 저장합니다. NVIDIA 429처럼 계획 이전에 실패하면 `execution_error`만 있고 `verification`은 `null`입니다.

보고서에는 harness 버전, request key, dataset/manifest/cutoff, task ID, 시도 번호, 단계 상태, 검사 규칙, 실패 코드, 산출물 해시, 최종 출력 해시와 보고서 해시가 있습니다. 원천 근거 해시는 ID뿐 아니라 검증한 값·위치·소스 메타데이터·원장 연결도 포함합니다. JSON 역직렬화 시 기록 범위와 해시 일치를 검사합니다. 이 해시는 재현·변경 탐지용이며 외부 서명이나 임의 코드 변조를 막는 보안 증명은 아닙니다.

- `verified`: 실행된 로컬 작업과 최종 출력의 필수 검증이 통과했습니다.
- `limited`: 상품 사실 조회를 수행하지 못해 검증된 제한 안내만 출력했습니다. 사실 답변 성공으로 집계하지 않습니다.
- `failed`: 실행 또는 검증에 실패했습니다. 최종 답변을 발행하지 않으며 출력 해시가 없습니다.
- 단계의 `not_run`은 미실행, `not_applicable`은 해당 경로에서 사용하지 않는 단계입니다. 둘 다 통과로 집계하지 않습니다.

현재 로컬 SQL 경로의 CalculationRecord 생성, 생산용 ClaimGate 출시, Graph·Vector 투영, 데이터셋 활성화, 별도 LLM judge는 `not_applicable`입니다. 이 보고서는 해당 기능을 실행하거나 전체 운영 출시를 승인한 기록이 아닙니다.

## 실제 확인 결과와 남은 제한

최종 전체 offline 시험은 **4,087 passed, 1 skipped, 519 deselected**였습니다. 외부 DB/API·원본·성능 시험을 제외한 결과이며 제외/미실행 항목은 통과로 취급하지 않습니다. 이후 근거 적재 취소·재시도 사례 1개를 추가했고 해당 의존 작업 시험 파일은 **4 passed**, 마지막 Harness·의존 작업 결합 시험은 **15 passed**였습니다. 전체 시험 건수에 이 좁은 시험 결과를 단순 합산하지 않습니다.

실제 로컬 DB에 정상 합성 의도 제안을 연결한 4개 질문 × 3회 재시험은 **7회 성공·5회 SQL 시간 초과**였습니다. 모델 통신만 교체했고 실제 컴파일·조회·근거·최종 출력 검증은 실행했습니다. 일본 주식형 ETF 20건과 보수/AUM 조건 ETF 13건은 각각 3회 성공했습니다. 원화·AA- 이상 채권은 3회 중 1회 성공(15,848건), 구매 가능 가정까지 적용한 전체 채권 질문은 3회 모두 시간 초과였습니다. 5초 SQL 제한은 변경하지 않았습니다.

별도 특정 상품 질문은 산은캐피탈770-4 1건을 1.93초에 반환했고 통화 KRW, 등급 AA-, 만기 2028-07-10, 잔존일수 689일(2026-08-21)과 원천 위치가 검증됐습니다. 이는 미래 만기와 구매 가능 **가정**의 검증이며 전체 채권 질문의 성능 통과나 실시간 판매 상태 확인을 뜻하지 않습니다.

기본 모델 `z-ai/glm-5.3-flash` 실제 NVIDIA 호출은 **429 / MODEL_RATE_LIMITED**로 계획 이전에 실패했습니다. 실제 모델을 포함한 이번 통합 재검증은 미완료입니다. 별도 LLM judge·추가 전송·DB 변경 없이 검증 경계를 보강했으며, 채권 전체 건수 조회 성능과 NVIDIA 호출 안정성은 후속 문제로 남습니다. 실행 로그는 원본 작업 폴더의 `data/verification-harness-20261012/`에 보존하고 Git에서 제외합니다.
