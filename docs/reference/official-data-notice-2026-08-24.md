# 2026-08-24 공식 데이터·평가 추가 공지

**기록일:** 2026-08-24

**성격:** 대회 주최 측 추가 공지의 프로젝트 적용 요약

**우선순위:** 이전 `2026-07-11` 데이터 배포와 충돌하는 경우 본 공지가 우선한다.

## 1. 공식 데이터 기준 변경

- `2026-07-11` 배포본에는 정합성 및 코드 관련 문제가 있으므로 최종 평가 기준으로 사용하지 않는다.
- 새 배포본은 네 테이블의 데이터·스키마 파일 각 1개, 총 8개 XLSX 파일이다.
- 새 데이터는 `2026-08-24` 배포 기준이며 국내 영업일 데이터는 주로 `2026-08-22`까지, 해외 데이터는 한국시간 `2026-08-23`까지를 대상으로 한다.
- 공시와 기타 시장 데이터는 `2026-08-24`까지 발행·이용 가능해진 공식 자료를 사용할 수 있다.

## 2. 코드·결측·구매 가능성

- 주최 측 내부 코드값 테이블은 제공되지 않으며, 해당 코드 자체의 의미를 묻는 평가는 출제하지 않는다.
- `0`과 빈 값은 의도된 원천값이다. 다른 값으로 보정하지 않고, 질의 결과에서는 생략하거나 값이 없다고 설명한다.
- 국내채권의 `BUYABLE_QUANTITY` 값은 무효이므로 구매 가능성 판단에 사용하지 않는다.
- 상장폐지 또는 리스팅 종료 종목을 제외한 종목은 구매 가능한 것으로 가정한다.

## 3. 외부 데이터와 정성평가

- 크롤링을 포함한 추가 데이터 수집은 허용되지만 신뢰성·무결성 관리는 참가팀의 책임이다.
- 보고서에는 데이터 수집 방법, 수집·적재 흐름, 활용 로직을 명시해야 한다.
- 저장소에 데이터를 단순 보관하는 것만으로는 정성평가 근거가 되지 않는다.
- 섹터–상품, 구성종목–상품 관계를 어떤 신뢰 가능한 데이터로 구축할지는 참가팀의 설계 범위다.

## 4. 평가 범위와 실행 제약

- 총 35문항: 상 10, 중 10, 하 10, 답변 불가 질의 5문항.
- 두 개 이상의 상품군을 함께 조회·비교하는 교차질의가 포함될 수 있다.
- 예시 형태: 삼성전자를 보유한 국내·해외 ETF와 공모펀드를 연간수익률 기준으로 함께 순위화.
- 300초는 물리적 미응답 타임아웃이며, 그 이내라도 더 빠른 응답에 유리한 차등이 존재한다.

## 5. LLM 적용

- 평가 API의 질의 Intent 분석과 답변 생성에는 NCP HyperCLOVA X를 사용한다.
- 데이터 조회, 증거 생성, 계산, 검증 등 중간 처리는 결정론적 코드와 승인된 도구로 수행할 수 있다.
- 프로젝트의 기존 한정형 오케스트레이션, 결정론적 계산, Evidence/Claim Gate 방향을 유지한다.
